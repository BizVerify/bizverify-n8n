# n8n-nodes-bizverify

[n8n](https://n8n.io/) community node for [BizVerify](https://bizverify.co) — verify business entities against official government registries.

## Install

1. Go to **Settings > Community Nodes** in your n8n instance
2. Enter `n8n-nodes-bizverify`
3. Click **Install**

## Credentials

1. Get an API key at [bizverify.co](https://bizverify.co) (50 free credits on signup)
2. In n8n, go to **Credentials > New Credential > BizVerify API**
3. Paste your API key

## Operations

| Operation | Description | Credits |
|-----------|-------------|---------|
| Verify Business | Verify a business entity in a jurisdiction | 1-25 |
| Search Entities | Search entities by name | 2/jurisdiction |
| Check Job Status | Check async job status | Free |
| Get Entity | Get cached entity details | Free |
| Get Entity History | Get verification history | 1 |
| Get Account | View account info | Free |
| Get Config | Get service configuration | Free |
| List Jurisdictions | List supported jurisdictions | Free |
| Purchase Credits | Purchase credits | N/A |
